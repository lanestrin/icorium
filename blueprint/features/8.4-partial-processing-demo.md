### Known limitations to document

- Source data is never repaired. A Needs Review input stays Needs Review after
  processing; fix the CSV and upload it again.
- Both rows of a duplicate batch ID are marked Invalid; neither is chosen as
  the "real" one.
- Comparison pairs rows by position in the file, not by batch ID. Files with
  different row orders or counts compare row by row.
- Only results from the same function and current column layout can be
  compared. Regenerate an older result before comparing it with a new one.
- Re-running a function on the same input replaces the earlier result. There
  is no version history.
- Processing is synchronous, one file at a time; fine for interview-sized files.
  Preview lists the first 100 problem rows in detail.
- Classification thresholds are demo-only, and no purity or recovery is
  inferred from composition.
- Automated tests do not check real-browser layout or visuals.
