# Feature: Remove or finish dead and partial code

**From build-plan:** feature 10.5
**Build attempt:** 1
**Branch:** `chore/dead-and-partial-code`
**Status:** verified

## Goal

Remove code that is unused, test-only or half-done, and finish the one partial
rule (the preview's red highlight) so it works on current results. Behaviour is
unchanged apart from that highlight.

## In scope

1. **Preview highlight.** In `client/src/components/Modals.tsx`, the preview cell
   rule `r[h] === 'ERROR'` only fires on legacy exports, since current results
   write `Invalid` in `processing_status`. Chosen option: mark a `processing_status`
   cell that reads `Invalid` in red, and keep marking any cell that reads exactly
   `ERROR` (legacy). Other `Invalid` text in other columns is not marked.
2. **`detectProcessor`.** Delete it from `server/src/processing/index.ts`; rewrite
   its test in `server/src/core.test.ts` (lines ~129–131) to use
   `detectResult(...)?.processor`.
3. **`seed` on `/api/generate`.** Drop `seed` from `generateBody` and the handler
   in `server/src/routes/files.ts`. Remove `seed` from the two API tests in
   `server/src/api.test.ts` (~809, ~822); they assert counts that hold for any
   seed (pinned for seeds 1–20 in `core.test.ts`). Repeatable generation stays
   tested through `generateCsv` / `generateFiles` in `core.test.ts`, which keep
   their optional `seed` parameter. Observed: Zod strips the unknown `seed` key, so a
   request that still sends it is accepted and the seed has no effect; an API test
   pins that two requests with the same seed give different data.
4. **Small cleanups.**
   - Delete the older duplicate doc comment above `Modal` (keep the "Dialog shell…"
     comment).
   - Stop exporting `Adapter` (`server/src/adapters/index.ts`), `TopDifference`
     and `FILE_COLORS` (`client/src/components/CompareWorkspace.tsx`), `fmtDate`
     (`client/src/components/FileTable.tsx`) and `DEMO_CLASS_RULES`
     (`server/src/processing/index.ts`). None is imported elsewhere, tests included.
     `topDifferences` stays exported with its return type still declared.
   - Rename `archiveTargets` to `selectedInView` in `client/src/App.tsx`.

## Out of scope

- Single-sourcing names and limits (10.6), adapter ids and `DIGITS` (10.7), and
  any other 10.x refactor.
- Changing generator randomness, the generator UI, or the result columns.
- Browser tests.
