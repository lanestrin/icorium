# Feature: Move file rules and workspace state out of the components

**From build-plan:** feature 10.8
**Build attempt:** 1
**Branch:** `refactor/client-structure`
**Status:** verified

## Goal

`FileTable.tsx` holds only table components, the file rules live in
`client/src/file-status.ts`, and `App.tsx` reads as layout wired to a few hooks,
each owning one concern. Nothing the person sees or does changes.

## In scope

1. **File rules → `client/src/file-status.ts`** (new; `file-status.test.ts`
   already tests these rules). Move, unchanged, from `FileTable.tsx`:
   `STATUSES`, `Status`, `displayStatus`, `QualityWarning`, `qualityWarning`,
   `Replacement`, `replacements`, `PROCESSING_FUNCTIONS`, `processingFunctionId`,
   `processingFunction`, `SortKey`, `SORT_OPTIONS`, the sort helpers and
   `sortFiles`, `importedLineage`, and the `Tab` type. Add one pure
   `filterFiles(files, filters, state)` holding the filter predicate now inline in
   `App.tsx`'s `useMemo` (search by name or File ID, tab, status with
   processing/failed overrides, function, date range by local day), followed by
   `sortFiles`.
   `FileTable.tsx` keeps `StatusBadge`, `FileTabs`, `RowMenu`, `FileTable`, its
   table-only constants and `fmtDate`, importing rules from `file-status.ts`.
   `Modals.tsx` and `App.tsx` import rules from `file-status.ts`.
2. **Workspace hooks → `client/src/hooks.ts`** (new, one file). `App.tsx` keeps
   the error and notice banners, preview, comparison and all JSX.
   - `useFileList(onError)`: `files`, `refresh` (keeps the numbered-request rule:
     only the latest list answer is used), and `upload(list)` with `uploading`.
   - `useSelection()`: `selectedIds`, `setSelectedIds`, `toggle`, `toggleAll`.
   - `useFilters()`: search, from, to, status, function, tab and per-tab sort
     state with their setters, `filtersActive`, `clearFilters`, `viewArchived`,
     `sort`.
   - `useArchive({ busy, refresh, deselect, onError })`: `archiving`, `toast`,
     `dismissToast`, `setArchived(ids, archive, undoable)`, and the 8-second toast
     timer.
   - `useProcessing({ files, busy, refresh, setSelectedIds, onError, onNotice, onPreview })`:
     `processor`, `setProcessor`, `processingId`, `failedIds`, `pending`,
     `cancelPending`, `requestRun(batch)`, `confirmRun`, and `run` with today's
     replace-conflict, failed-file and selection rules.
   - App creates the one `busy` ref and passes it to both `useArchive` and
     `useProcessing`, so a double click still cannot start an archive and a batch
     together.
3. **Docs.** README layout line for `client/src` and the Architecture page's
   frontend node `files` list name `client/src/file-status.ts` and
   `client/src/hooks.ts`; the README test table row for `file-status.test.ts`
   adds filtering.

## Out of scope

- Any change to UI text, layout, behaviour, timing or API calls.
- Splitting `FileTabs` or `RowMenu` into their own files, or touching
  `CompareWorkspace`, `GeneratorPage` or `Sidebar`.
- Storage, caching, settings (10.9–10.12). Browser tests.
