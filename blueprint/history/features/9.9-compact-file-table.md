# Feature: Compact file table

**From build-plan:** feature 9.9
**Build attempt:** 1
**Branch:** `feature/9.9-compact-file-table`
**Status:** verified

## Goal

Simplify the CSV Files table by removing the **Rows** and **Columns** columns
from both the **Active Files** and **Archived** tabs, so **File Name** gets
more room. Row and column counts stay available in **Preview**. This is a
presentation-only change, requested by the person on 2026-11-11.

## Design reference

The person's compact-table mockup:
[`blueprint/reference/9.9-compact-file-table.png`](../reference/9.9-compact-file-table.png).
Its own caption says it is illustrative and that the Uploaded date remains in
the full-width table. Only the removal of Rows and Columns is taken from it.
Its ⋯ action menu for every row and its "Active Files · 20 files" header are
not part of this item (see Out of scope). The existing table styling and
`blueprint/reference-ui.png` still apply.

## In scope

- **File table** (`client/src/components/FileTable.tsx`):
  - Remove the **Rows** and **Columns** header cells and body cells.
  - Column order: checkbox, **File ID**, **File Name**, then the date columns,
    then **Processing function**, **Status** and **Actions**.
  - Date columns: **Uploaded** in Active Files. In Archived, **Archived On**
    and **Original Upload** stay as they are, preserving the existing date
    information.
  - The empty-state cell spans the new column count: 7 in Active Files, 8 in
    Archived.
  - Lower the table's minimum widths so File Name takes the freed space:
    `min-w-[1180px]` becomes about `min-w-[1000px]`, and `min-w-[1340px]`
    becomes about `min-w-[1160px]`. The exact values are tuned in step 1.
  - No fixed column widths are added. The table keeps scrolling inside its
    own labelled region at phone width, with no sideways page scroll.
- **Preview header** (`client/src/components/Modals.tsx`, `PreviewModal`).
  The title stays the filename. The existing subtitle becomes:
  - input: `File ID 101010 · 25 rows · 7 columns`
  - result: `File ID 101010-V · Composition Validation result · 25 rows · 12 columns · generated columns highlighted`
  - The 11.7 imported suffix is kept.

  Today a result's subtitle shows no column count. No new cards or elements.
- **README:** where it describes the file table's columns, if it does.

## Out of scope

- The mockup's ⋯ action menu on every row, its card header with a file count,
  and any other restyling.
- Any change to upload, processing, File IDs, archive and restore,
  comparison, selection and bulk actions, filters, sorting, downloads, the API
  or stored metadata. `FileMeta.rows` and `FileMeta.columns` stay.
- Other places that show row counts, such as the Data Quality Warning and the
  comparison.
