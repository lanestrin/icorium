## Problem and outcome

7.1 is an integration review, not a redesign. A review of the docs against the
code on 2026-11-09 found several problems:

- the client tests miss part of the P0 workflow;
- some README and plan details are out of date;
- the stack doc contradicts the approved Vercel setup and still has a manual
  checklist.

Fix these so the README, plan and tests describe the app as it is.

## Review findings

### Coverage (the P0 workflow)

Server unit/API tests cover every endpoint and all 15 sample × function cases.
The client component tests (`App.test.tsx`, 13 cases) cover selection, filters,
processing and the warning dialog. **No client test** covers these:

| P0 step | Untested client behavior |
| --- | --- |
| Load a CSV | Upload through the file input: success refreshes the list; a failed file shows `Upload failed` with its name and message |
| View input rows | Preview paging (**Show N more** loads the next page), the load-error message and the Download link |
| Load two results, compare | Footer: Compare disabled until two distinct results; File B lists only results from File A's function; changing A to another function clears B |
| Comparison graph | Compare success opens the modal with both file names, the per-file problem cards and the summary table; failure shows `Comparison failed: …` |
